\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Application modernization requires understanding the existing system, resolving version incompatibilities, transforming the code, and revalidating the application after each evolution. Carried out at \textbf{CGI Technologies and Solutions Morocco}, this final-year engineering project aims to design an \textbf{intelligent, extensible, and governed Migration Factory} in order to automate a significant part of this process while preserving developer control over sensitive decisions.

The main contribution lies in a \textbf{governed multi-agent-system architecture}, combining a hybrid design with central orchestration, in which critical operations remain under deterministic control and human supervision. The project was conducted incrementally and iteratively, from requirements analysis and architectural design through implementation, technical verification, and the execution of representative scenarios.

The results demonstrate an \textbf{operational Java/Spring Boot trajectory}, progressively covering Spring Boot 2.1, 2.7, 3.5, and 4.0 with Java versions adapted to each stage. Three successive demonstrations validated the evolution from a command-line prototype to a full-stack \textit{Control Tower}. The Java implementation includes isolated workspaces, Maven-based validation, a governed repair loop, a supervision cockpit, an assistant, and reporting that preserves technical evidence. For \textbf{Angular}, the 18-to-19 and 19-to-20 transitions were executed and sealed; the 20-to-21 stage is prepared but has not started. These results demonstrate the Factory's ability to structure migration work stage by stage, link decisions to evidence, and strengthen traceability, thereby allowing the developer to supervise a more explicit and reproducible process.

Quantitative evaluation of overall time, cost, and productivity gains still needs to be consolidated on a representative corpus; this remains an evaluation perspective rather than a limitation on the technical results already demonstrated.

\vspace{0.4cm}
\noindent\textbf{Keywords:} Angular, Java/Spring Boot, multi-agent systems, software migration, traceability.
