\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Application modernization remains costly in time and expertise because it combines legacy understanding, compatibility resolution, code transformation, tool execution, validation, and repeated diagnostic cycles. This final-year engineering project, carried out at \textbf{CGI Technologies and Solutions Morocco}, aims to design an \textbf{intelligent, extensible, and governed Migration Factory} able to automate a significant part of this process while preserving developer control over sensitive decisions.

The proposed solution relies on a hybrid, centrally orchestrated multi-agent architecture. Agents are reserved for tasks that require reasoning or adaptation, including analysis, planning, review, agentic transformation, repair, and assistance. Critical and verifiable operations remain under deterministic services that control workflow state, transitions, commands, writes, validations, and evidence preservation. The project was conducted incrementally through requirements analysis, architectural design, component implementation, technical verification, representative scenarios, and progressive integration of feedback.

Two independent implementations were developed. The first targets \textbf{Java/Spring Boot} and is the most mature implementation, with a progressive migration path, isolated workspaces, Maven-based validation, a governed repair loop, a cockpit, an assistant, and reporting capabilities. It also integrates Azure OpenAI through externalized configuration that maps model deployments to agent roles. The second implementation targets \textbf{Angular} in order to assess the transferability of the architecture to another ecosystem. The retained execution evidence validates the Angular 18-to-19 and 19-to-20 transitions; the 20-to-21 stage is prepared but has not started, while the complete 11-to-21 trajectory remains to be completed.

The evaluation mainly highlights the value of separating reasoning, decision-making, and execution in order to improve traceability, reproducibility, and migration governance. Overall gains in time, cost, and productivity have not yet been quantitatively demonstrated on a representative corpus. The main contribution is therefore a governed architecture that increases migration automation while preserving deterministic safeguards, technical evidence, and human supervision.
