\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Application modernization often remains costly in time and expertise because it combines project analysis, compatibility resolution, code transformation, tool execution, testing, and repeated diagnostic cycles. This final-year engineering project, carried out at \textbf{CGI Technologies and Solutions Morocco}, addresses this challenge through the design of an \textbf{intelligent, extensible, and governed Migration Factory}.

The solution relies on a hybrid, centrally orchestrated multi-agent architecture. Agents handle tasks that require reasoning or adaptation, including analysis, planning, review, agentic transformation, repair, and assistance. Sensitive and verifiable operations remain under deterministic services that control workflow state, transitions, commands, writes, validations, and evidence preservation. The developer therefore retains authority over important decisions.

Two independent implementations were developed. The first targets \textbf{Java/Spring Boot} and is the most mature implementation, with a progressive migration path, isolated workspaces, Maven-based validation, a governed repair loop, a cockpit, an assistant, and reporting capabilities. It also integrates Azure OpenAI through externalized configuration that maps distinct model deployments to agent roles. The second implementation targets \textbf{Angular}. The retained execution evidence validates the Angular 18-to-19 and 19-to-20 transitions; the 20-to-21 stage is prepared but has not started, while the broader 11-to-21 trajectory remains to be completed.

The results mainly demonstrate the value of separating reasoning, decision-making, and execution in order to improve traceability, reproducibility, and process control. However, overall gains in time, cost, and productivity have not yet been quantitatively demonstrated on a representative corpus. The main contribution is therefore a governed architecture that increases migration automation while preserving deterministic safeguards and human supervision.

\noindent\textbf{Keywords:} Software migration, application modernization, multi-agent systems, LLM, orchestration, Java, Spring Boot, Angular, Azure OpenAI, traceability, human-in-the-loop.
